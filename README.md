# Финальный проект по Selenium

Здесь собраны решения финальных заданий курса по автоматизации тестирования на Python.
Проект использует паттерн Page Object.

## Структура проекта:
- `conftest.py` — фикстура для запуска браузера.
- `test_product_page.py` — тесты для страницы товара.
- `pages/` — папка с Page Object классами.
